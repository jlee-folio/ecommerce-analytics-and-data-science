## Online Retail Analysis

#### Project Overview:
Developed a reproducible Python analytics pipeline that transforms transitional retail data into executive KPIs, sales and product performance analyses, customer-level metrics, RFM segments, pricing insights, and automated business reports. Include data-quality assessment, documented metric definitions, and actionable recommendations for retail decision-making. An exploratory data analysis and data science project focused on online retail transactions.

#### Objectives:
- Analyze sales and revenue trends.
- Identify top-performing products.
- Understand customer purchasing behavior.
- Generate actionable business insights.

#### Tools & Technologies:
Python,
Pandas,
NumPy,
Matplotlib,
Seaborn,
docx
and Jupyter Notebook
